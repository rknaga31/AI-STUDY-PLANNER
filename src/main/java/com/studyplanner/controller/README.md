# Frontend Controllers Package (`com.studyplanner.controller`)

This package contains the presentation controllers managing JavaFX views, user interaction events, and reactive table data.

## Modules & Classes
- **[`MainViewController.java`](file:///c:/Users/rnaga/.antigravity-ide/studyplanner/src/main/java/com/studyplanner/controller/MainViewController.java)**: Navigation shell, sidebar, header status bar, and view routing.
- **[`LoginController.java`](file:///c:/Users/rnaga/.antigravity-ide/studyplanner/src/main/java/com/studyplanner/controller/LoginController.java)**: Authentication and registration screen.
- **[`DashboardController.java`](file:///c:/Users/rnaga/.antigravity-ide/studyplanner/src/main/java/com/studyplanner/controller/DashboardController.java)**: Metric cards, priority spotlight, and today's schedule summary.
- **[`SubjectController.java`](file:///c:/Users/rnaga/.antigravity-ide/studyplanner/src/main/java/com/studyplanner/controller/SubjectController.java)**: Subject registration, difficulty badges, and exam scheduling dialogs.
- **[`PlannerController.java`](file:///c:/Users/rnaga/.antigravity-ide/studyplanner/src/main/java/com/studyplanner/controller/PlannerController.java)**: Study plan generation, hours input, and explainable AI cards.
- **[`ProgressController.java`](file:///c:/Users/rnaga/.antigravity-ide/studyplanner/src/main/java/com/studyplanner/controller/ProgressController.java)**: Study session logging dialog, topic adjustments, and session history table.
- **[`ProfileController.java`](file:///c:/Users/rnaga/.antigravity-ide/studyplanner/src/main/java/com/studyplanner/controller/ProfileController.java)**: Student profile preferences and database status testing.
